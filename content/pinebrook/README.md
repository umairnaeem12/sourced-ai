Sample help docs for Pinebrook Supply, a fictional home and kitchen store used by the Sourced AI demo. Every policy, price, address and order number here is made up.

`npm run ingest` loads every `.md` file in this folder as a sample doc. This README is not ingested.

Price matching, student discounts and payment plans are left out on purpose, so the demo can show how Sourced AI handles a question its docs don't cover.
